<h1>🏫 Master Attendance</h1>
<p>النظام الذكي لمراقبة حضور التلاميذ في المؤسسات التربوية بالباركود</p>

<br>

<h2>📌 نبذة عن البرنامج</h2>
<div style="width:180px;height:3px;background:#4CAF50;margin:5px 0 15px 0;"></div>

<p>
<strong>ماستر أتندنس (Master Attendance)</strong> هو برنامج متكامل مخصص للإدارات والمؤسسات التربوية العمومية، يهدف إلى رقمنة وضبط عملية مراقبة حضور وغياب التلاميذ بدقة وسرعة فائقة عند بوابة المؤسسة، مع توفير تقارير فورية وتواصل مباشر مع أولياء الأمور.
</p>

<ul dir="rtl">
<li>تسجيل الدخول والخروج الفوري للتلاميذ عبر مسح رمز الباركود (Barcode) الفريد لكل تلميذ عند البوابة</li>
<li>استخراج تقارير وإحصائيات الحضور والغياب اليومية والشهرية بضغطة زر</li>
<li>إرسال إشعارات ورسائل فورية لأولياء الأمور لإعلامهم بغياب أو تأخر أبنائهم عبر <strong>SMS</strong> أو <strong>WhatsApp</strong> أو <strong>Telegram</strong></li>
<li>توليد وطباعة بطاقات التلاميذ المزودة بالباركود الخاص بكل تلميذ بسهولة</li>
<li>تخفيف العبء الإداري وتوفير الوقت والجهد لطاقم الاستشارة التربوية والإدارة</li>
</ul>

<br>
